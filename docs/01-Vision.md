# 01 - Visión del Proyecto

## Nombre del proyecto
**DevPortfolioMVC**

## Descripción general
DevPortfolioMVC será una aplicación web desarrollada con ASP.NET Core MVC cuyo objetivo será administrar y publicar el portfolio profesional de Ezequiel Benítez.

## Objetivo principal
Construir un portfolio profesional que demuestre conocimientos de desarrollo backend, arquitectura, bases de datos, autenticación y buenas prácticas.

## Filosofía del proyecto
- Calidad antes que velocidad.
- Simplicidad antes que complejidad innecesaria.
- Documentación desde el primer día.
- Código mantenible.
- Decisiones técnicas justificadas.
- Evolución por versiones.

| Término              | Significado                                                                                         |
| -------------------- | --------------------------------------------------------------------------------------------------- |
| **RutaRelativa**     | Ruta del recurso dentro de la aplicación. No representa un archivo ni un objeto de infraestructura. |
| **RepositorioUrl**   | URL del repositorio GitHub del proyecto.                                                            |
| **DemoUrl**          | URL de la aplicación desplegada.                                                                    |
| **Slug**             | Identificador único amigable para formar URLs.                                                      |
| **Contexto**         | Origen del proyecto (Personal, Académico, Laboral, Freelance, Challenge).                           |
| **Nivel de Madurez** | Nivel de evolución del proyecto (Experimental, Académico, Portfolio, Profesional).                  |
